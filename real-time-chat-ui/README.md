# Real-Time Chat UI

A frontend-only, mock-data React + Vite chat UI demo with Tailwind CSS and Vitest tests.

Commands:

- npm install
- npm run dev (start dev server at http://localhost:3000)
- npm run build
- npm run preview (preview built app)
- npm test (run unit tests)

This project uses Zustand for state management and the UI uses a simple component architecture (ConversationList, ChatWindow, MessageInput, Contacts, SearchBar).
