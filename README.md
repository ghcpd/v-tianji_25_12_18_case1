# Real-Time Chat UI

A small frontend-only chat UI built with React + Vite + TypeScript and mock realtime data.

Scripts

- npm install
- npm run dev
- npm run test
- npm run test:coverage

Features

- Conversation list
- Message thread view
- Search conversations
- Contacts management (add contact)
- Mock realtime messages via in-memory service

Tests

Unit tests implemented with Vitest and @testing-library/react
