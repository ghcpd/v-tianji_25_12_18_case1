### All Source Code Files
- src/types.ts: Type definitions for Contact, Message, Conversation.
- src/mockData.ts: Mock data for contacts, messages, conversations.
- src/ChatContext.tsx: React Context for state management.
- src/components/SearchBar.tsx: Search input for chat history.
- src/components/ConversationList.tsx: List of conversations with filtering.
- src/components/MessageThread.tsx: Display messages in selected conversation.
- src/components/MessageInput.tsx: Input to send messages.
- src/components/ContactList.tsx: Manage contacts (add/remove).
- src/App.tsx: Main app component with layout.
- src/App.css: Basic styling.

### All Test Files
- src/App.test.tsx: Tests rendering of main components.
- src/components/ConversationList.test.tsx: Tests conversation list rendering and selection.
- src/components/MessageInput.test.tsx: Tests message input behavior.

### All Configuration Files
- package.json: Dependencies and scripts.
- tsconfig.json: TypeScript configuration.
- .gitignore: Git ignore rules.
- public/index.html: HTML template.
- src/index.tsx: App entry point.
- src/setupTests.ts: Test setup.

### Commands Used

- `cd chat-app; npm start`: Start development server.
